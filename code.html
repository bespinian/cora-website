Reasoning über das ganze Repo

256k Kontext, Indexierung auf Symbolebene und Dependency-Graphen - damit Refactorings auch den Kontakt mit einem 15 Jahre alten Monolithen überstehen.

Sandboxed Execution

Befehle laufen in einem kurzlebigen Workspace mit einer Allow-List-Toolchain und standardmässig ohne Egress.

Diff-First-Review

Nichts wird ohne überprüfbaren Diff geschrieben. Plan-only-Modus für Tier-1-Repositories.

Überall, wo Engineers arbeiten

CLI, VS Code, JetBrains und headless cora run in GitLab- oder GitHub-Enterprise-Pipelines.

Dein Kontext, deine Tools

MCP-Server, interne APIs, Ticketing und dein Service-Katalog - pro Projekt deklariert in AGENTS.md.
