Ce qu'est Cora Code

Un ensemble de modèles à poids ouverts qui écrivent du code, exploités sur des GPU suisses ou dans votre propre centre de données. Au-dessus, une API tout à fait ordinaire : ce qui parle à OpenAI aujourd'hui parle à Cora demain.

Les modèles

Des modèles à poids ouverts, taillés pour le code, exploités sur des GPU suisses. Choisissez par espace de travail - ou laissez la passerelle router : les petites modifications au modèle rapide, le raisonnement difficile au plus puissant.

Modèle Contexte Idéal pour
Cora Deep 256k Travail agentique sur de nombreux fichiers
Cora Swiss 128k Code et documentation en allemand, français et italien
Cora Fast 64k Complétion, tests, hygiène des commits
Votre propre fine-tune - Frameworks internes et code légataire

Cora Deep et Cora Fast sont dérivés de Qwen3-Coder, Cora Swiss d'Apertus. Tous trois sont sous Apache-2.0 : vous pouvez télécharger les poids et les emporter.

Les fournisseurs hébergés - aujourd'hui les modèles OpenAI - passent par les mêmes politiques, mais tournent sur l'infrastructure du fournisseur et non sur des GPU suisses. Ils sont bloqués par défaut ; un tenant les ouvre par équipe et par classe de données, ou pas du tout. État : septembre 2026.

Là où vos ingénieurs travaillent déjà

CLI, VS Code, JetBrains et headless dans la pipeline - le tout via une base URL compatible OpenAI. Vos serveurs MCP, API internes et outils se déclarent par projet dans AGENTS.md.

Chaque token consommé par Cora Code passe par Cora Gateway : les mêmes politiques et le même journal d'audit que partout ailleurs.
